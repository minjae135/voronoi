# 보로노이 탐험실

수학 축전에서 보로노이 다이어그램을 설명할 때 사용하는 인터랙티브 시각화입니다. 생성점을 놓고, 각 점에서 퍼지는 파동과 점 사이의 영역을 관찰할 수 있습니다.

## 기능

- **생성점 추가·이동:** `생성점 찍기`를 켜면 화면 클릭으로 점을 추가합니다. 모드를 끄면 점을 드래그해 옮길 수 있습니다. 마우스와 터치를 모두 지원합니다.
- **원형 파동:** 재생하면 모든 생성점에서 파동이 동시에 퍼집니다. 파동은 각 점에 가장 가까운 영역 안에서 진행하고, 영역 경계에서 다른 파동과 만납니다.
- **삼각분할:** 델로네 삼각분할을 겹쳐 볼 수 있습니다.
- **수직이등분선:** 인접 영역의 생성점 쌍 또는 모든 생성점 쌍의 수직이등분선을 표시할 수 있습니다.
- **셀 색상:** 경계를 맞댄 보로노이 영역에는 서로 다른 색을 사용합니다.

## 실행

Node.js 20.19 이상 또는 22.12 이상이 필요합니다.

```sh
npm install
npm run dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 엽니다.

## 프로덕션 빌드

```sh
npm run build
npm run preview
```

빌드 결과는 `dist/`에 생성됩니다.

## GitHub Pages

Vite 설정은 상대 경로를 사용하므로 저장소 하위 경로에서 앱을 서비스할 수 있습니다. `npm run build`로 만든 `dist/`를 GitHub Pages의 게시 대상으로 설정하세요. 이 저장소에는 자동 배포 워크플로가 포함되어 있지 않습니다.

## 프로젝트 구조

```text
index.html          앱의 HTML 진입점
src/main.ts         화면 조작과 애니메이션
src/geometry.ts     보로노이 셀, 인접 관계, 삼각분할 계산
src/style.css       화면 스타일과 반응형 레이아웃
vite.config.ts      Vite 및 Pages 상대 경로 설정
```
